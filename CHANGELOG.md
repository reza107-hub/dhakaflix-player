# Changelog

## 1.1.0 – more servers

- Four DhakaFlix servers built in: DHAKA-FLIX-14, DHAKA-FLIX-7, DHAKA-FLIX-12
  and DHAKA-FLIX-10. Turn each on or off in Settings, or add your own.
- Search looks in all servers at once. Results appear as each server answers,
  show which server they are on, and can be filtered to one server. If a
  server does not answer, the others still show, with a note.
- Home lists the folders of each server. Continue watching works across all
  servers.
- Your watch history and resume positions from 1.0.0 are kept.
- Fixed a crash when leaving the player while the next episode was loading.

## 1.0.0 – first release

- Search DhakaFlix by name (folders and files), browse folders, episodes in
  natural order.
- Plays H.264, HEVC (including 10-bit), AC3, E-AC3 and DTS directly with
  hardware decoding when available. No transcoding.
- Audio track menu with language names; remembers your preferred language.
- Subtitles: embedded text tracks (SRT, ASS with styling) and matching
  `.srt` / `.ass` / `.vtt` files in the same folder. Size and delay controls.
- Versions menu to switch between 720p / 1080p / 2160p of the same title
  without losing your place.
- Resume where you stopped, Continue watching on the home screen, auto-play
  next episode with a 5-second countdown.
- Reconnects automatically after a network drop and continues from the same
  spot.
- Speed 0.5×–2×, double-tap to skip, landscape fullscreen on phones, keyboard
  shortcuts on desktop (Space, ←/→, ↑/↓, F, M, Esc).
- Everything stays on the device: no account, no analytics.
